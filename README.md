# Library

Independent reusable libraries organized by language.

- [`typescript/otel-neuron-connector/`](typescript/otel-neuron-connector/) — framework-independent OTel Neuron Connector. The DeepSeek Harness plugin is a separate consumer and is maintained in `qdev-dsh-plugins`.

Each library keeps its own package identity, tests, and release lifecycle. This repository is itself an independent Git repository and may be mounted under `qdev-dsh-plugins/library/` as a submodule.
